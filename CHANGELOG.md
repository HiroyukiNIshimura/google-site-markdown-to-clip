# Change Log

All notable changes to the "google-site-markdown-to-clip" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.1.1] - 2026-09-25
- Fix README and documentation references.

## [1.1.0] - 2026-09-25

- Add Mermaid.js support for rendering `language-mermaid` code blocks in Google Sites.
- Detect the asynchronously generated Markdown container before rendering Mermaid diagrams.

## [1.0.0] - 2026-09-24

- Copy the active Markdown document or selection as a Google Sites markdown script.
- Add the command to the Markdown editor context menu.
- Escape template-literal syntax safely in copied Markdown.
